# GitHub Public Repo Cloner Bot

Телеграм-бот: принимает ссылку на **публичный** репозиторий GitHub,
скачивает его, вырезает чувствительные файлы и отдаёт ZIP с полной
структурой папок, готовый для заливки в новый репозиторий как есть.

## Что вырезается

- Ключи и сертификаты: `*.pem`, `*.key`, `*.p12`, `id_rsa*`, `*.jks` и т.п.
- Файлы окружения с секретами: `.env`, `.env.*`, `*.env`
- `.gitignore`, `.gitattributes` и служебные папки `.git/`, `.github/`
- Разная конфиденциальная конфигурация: `credentials*`, `*secret*`,
  `*.tfstate`, `*.tfvars`, `service-account.json` и т.п.
- Мусорные каталоги: `node_modules/`, `venv/`, `__pycache__/`, `dist/` ...

Правила заданы в `cloner_bot.py` (`EXCLUDE_DIRS`, `EXCLUDE_EXACT`,
`EXCLUDE_GLOBS`) ... легко расширяются.

## Запуск

```bash
pip install -r requirements.txt   # нужен также установленный git
export TELEGRAM_TOKEN="123:ABC..."
python cloner_bot.py
```

Затем в Telegram: `/start`, пришлите ссылку вида
`https://github.com/owner/repo` ... в ответ придёт `repo.zip`.

Бот работает только с публичными репозиториями: учётные данные для
клонирования не используются, приватные клонировать не будет.

## Заливка в новый репозиторий на вашем GitHub

Бот может не просто отдать ZIP, а сразу создать **новый** репозиторий на
вашем аккаунте и залить туда очищенное содержимое ... без секретов и
**без старой истории коммитов** (свежий первый коммит, чтобы вырезанные
ключи не утекли через историю).

Нужен GitHub Personal Access Token с правом `repo`.

```text
/settoken <ваш_PAT>                       # один раз, лучше в личке боту
/push <ссылка> [имя_нового_репо] [public|private]
```

Пример:

```text
/push https://github.com/psf/requests requests-clean private
```

- Имя нового репозитория по умолчанию равно имени исходного.
- Видимость по умолчанию ... приватная (`DEFAULT_NEW_REPO_PRIVATE`).
- Токен можно задать глобально переменной `GITHUB_TOKEN`, тогда `/settoken`
  не обязателен.

Токен нигде не печатается: в ответах и логах он затирается, а сообщение
с `/settoken` бот пытается удалить из чата.

### Режим keephistory

По умолчанию `/push` заливает репозиторий **одним чистым коммитом** (старая
история не переносится, чтобы вырезанные ключи не утекли через старые
коммиты).

Если нужна полная история коммитов, добавьте `keephistory`:

```text
/push https://github.com/owner/repo my-repo private keephistory
```

В этом режиме история сохраняется (сообщения, авторы, даты), но чувствительные
файлы вырезаются **из всех коммитов** через `git-filter-repo`. Коммиты, которые
после чистки стали пустыми, схлопываются, а SHA коммитов меняются (это
неизбежно при переписывании истории).

Для этого режима нужен `git-filter-repo`:

```bash
pip install git-filter-repo
```
